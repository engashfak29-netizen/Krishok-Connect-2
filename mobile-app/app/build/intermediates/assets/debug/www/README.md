# Krishok Connect — কৃষকের সোস্যাল + মার্কেটপ্লেস + AI প্ল্যাটফর্ম

আপনার দেয়া থিম (JPG) অনুসরণ করে সম্পূর্ণ একটি মাল্টি-পেজ ওয়েব অ্যাপ (PWA) তৈরি করা হয়েছে। এটি
প্লেইন HTML/CSS/JavaScript দিয়ে বানানো — কোনো ইনস্টলেশন বা বিল্ড স্টেপ ছাড়াই সরাসরি ব্রাউজারে চলবে।

## চালানোর উপায়
`index.html` ফাইলটি সরাসরি ব্রাউজারে খুলুন, অথবা যেকোনো স্ট্যাটিক হোস্টিং (GitHub Pages,
Netlify, Firebase Hosting, বা আপনার নিজের সার্ভার) এ পুরো ফোল্ডারটি আপলোড করুন।
মোবাইলে "Add to Home Screen" করলে এটি PWA হিসেবে ইনস্টল হবে (manifest.json + sw.js যোগ করা আছে)।

## AI ফিচার সম্পর্কে
`ai.html` আপনার আগের "ফসল বন্ধু" প্রজেক্টের সার্চ ইঞ্জিন (`ai-search-engine.js`,
`ai-data-loader.js`, `ai-fallback-data.js`) পুনর্ব্যবহার করে তৈরি — বাংলা/ইংরেজি ফোনেটিক
ফাজি ম্যাচিং, ভয়েস সার্চ, এবং Google Sheet থেকে লাইভ ডেটা লোড (ব্যর্থ হলে বান্ডিল করা
ফলব্যাক ডেটা ব্যবহার করে)। এর সাথে নতুন "উপসর্গ বলুন" ট্যাব যোগ করা হয়েছে যেখানে ব্যবহারকারী
সাধারণ ভাষায় সমস্যা লিখলে নিয়মভিত্তিক (rule-based) পরামর্শ পান।

## ডেটা ও স্টেট
সব পোস্ট/পণ্য/চ্যাট/নোটিফিকেশন ডেমো ডেটা `app-data.js`-এ আছে এবং ব্রাউজারের
`localStorage`-এ সংরক্ষিত হয় (নতুন পোস্ট, লাইক, মেসেজ ইত্যাদি রিফ্রেশের পরও থাকবে)।
এটি একটি ফ্রন্টএন্ড প্রোটোটাইপ — আসল ব্যাকএন্ড/ডেটাবেজ (যেমন Firebase, Supabase, বা
কাস্টম API) যুক্ত করতে চাইলে `app-data.js`-এর `KC` অবজেক্ট এবং `kcSave()`/`kcLoad()`
ফাংশনগুলো প্রতিস্থাপন করলেই বাকি সব UI কোড অপরিবর্তিত থাকবে।
